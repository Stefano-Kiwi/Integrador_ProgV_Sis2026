# Planificación del Proyecto — FitZone Sports

En este directorio se encuentra la documentación oficial de planificación y gestión del proyecto para el Trabajo Integrador Final (TIF) de **FitZone Sports (Grupo 12)**:

- 📋 **[Plan de Proyecto (Anexo H)](plan-de-proyecto.md):** Documento maestro estructurado bajo los 8 apartados del Anexo H:
  1. **Alcance:** Definición formal de componentes incluidos y exclusiones justificadas.
  2. **Supuestos y Restricciones:** Supuestos operativos, restricciones académicas, de equipo y tecnológicas impuestas.
  3. **Equipo:** Nómina de integrantes, roles de liderazgo asignados, carga horaria comprometida (15 hs/sem) y áreas de responsabilidad.
  4. **Estructura de Desglose del Trabajo (EDT / WBS):** Jerarquía de 8 Épicas, 22 Historias de Usuario y Subtareas técnicas con horas estimadas y asignación nominal.
  5. **Cronograma:** Planificación de los 8 Sprints a lo largo de 12 semanas con objetivos, capacidades y entregables de cierre.
  6. **Matriz de Trazabilidad:** Cruce exhaustivo y bidireccional de requisitos funcionales (**RF-01 a RF-14**), reglas de negocio (**RN-01 a RN-03**) y requisitos no funcionales (**RNF-01 a RNF-04**) con historias de usuario, archivos de código del backend y casos de prueba automatizados.
  7. **Seguimiento por Sprint:** Comparativa entre esfuerzo comprometido, completado, trabajado real y desvíos observados.
  8. **Registro de Riesgos y Análisis de Desvíos:** Matriz de gestión de riesgos, justificación de estimaciones subestimadas, riesgos materializados/absorbidos y lecciones aprendidas de replanificación.
